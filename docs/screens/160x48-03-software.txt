 steamcmd.app_id (int, required): Steam app id of the dedicated server
 The server's own app id, not the game's: Valheim's is 896660. Search steamdb.info for 'dedicated server'.
 Downloads the server with steamcmd in a build stage and copies it into the image, pinned to a Steam build.
